## 3. 已落地的能力

### 后端（`backend/`，独立 `.venv`，Python 3.13）

- 热 JSON 配置（原子写、revision 冲突、监听器回滚）、SQLite + Alembic（WAL/外键）、仓储层。
- 指标协议：唯一名称、冻结参数模型、`calculate` 单一入口、主图/副图/逐点标记、命名空间化与输出校验、启动发现内置与 custom 模块。
- 计算 API：日/周/月（周月由日线聚合）、`asyncio.to_thread`、单指标失败隔离。
- Task 框架：唯一名称、单实例配置、标准五段 Cron（croniter `day_or=True`）、防重入、持久化历史/日志、取消与崩溃恢复。
- 应用组装：`create_app`、容器、生命周期、限流（客户端容量硬上限、失败关闭）、流式请求体限制、Host/Origin 信任边界。
- 数据源：AKShare/BaoStock（A/HK）、yfinance（US/HK 指数）、CCXT（Binance/OKX）、Invesco QQQ、iShares SOXX、恒指官方 factsheet；成交量统一为**股**。
- 同步语义：完整请求后才落库、单票事务、qfq 重叠变化触发二次全量、全量替换要求覆盖所有已存区间日期、空增量视为无新数据、断点续跑、partial/failed 聚合、超时与 Retry-After、区间强制、可诊断但脱敏的日志。
- **生产静态服务**：`configure_frontend` 只挂载 `/assets`，SPA 兜底由 404 处理器完成（因此 `create_app` 之后注册的路由不会被遮蔽）；`/api/**` 的 404 始终是 JSON；目录解析顺序为显式值 → `STOCK_LAB_FRONTEND_DIST` → 仓库相对 `frontend/dist`（不依赖 CWD）；`serve_frontend=False` 可完全关闭。

### 前端（`frontend/`，React 19 + TS 5.9 + Vite 8）

- `ApiResult{data,meta}` 客户端：**强制 decoder**、运行时 DTO/元数据校验、错误脱敏、同源路径限制、409/revision 元数据保留。
- `SchemaForm`：冻结输入/输出克隆、`submitText`、字段类型/默认值/边界/nullable/disabled。
- **图表层**（`src/charts/`）：Lightweight Charts 5.2，主图蜡烛 + 成交量共用 pane 0，副图按请求顺序建制，`createSeriesMarkers` 绑定蜡烛或命名序列，参考线挂在所属序列；`null` → whitespace，NaN/Infinity、重复或非递增日期、marker 日期不存在、marker/参考线指向未知序列一律拒绝并提示；移除指标先删序列（最高 pane 优先）再清 pane，蜡烛与成交量始终保留；ResizeObserver 忽略 0 尺寸，卸载时断开并销毁图表。
- **分析页**（`src/features/analysis/`）：证券搜索（300ms 防抖）、日/周/月、日期区间（默认最近两年，两个独立日期选择器）、同一指标多实例（UUID `instance_id`）、参数编辑、350ms 防抖批量计算、单指标错误隔离、空库引导。
- **Task 页**（`src/features/tasks/`）：Task 表、配置抽屉（五段 Cron 前端校验含范围检查、启停、RJSF 参数表单）、立即执行（与调度开关无关）、运行历史与日志、运行中 2s 轮询并在终态/卸载停止、409 刷新并要求重新确认、429 提示。
- **设置页**（`src/features/settings/`）：分市场 provider（受后端 allowlist 约束）、历史深度（可切「全部可用历史」）、超时/重试/重叠天数、加密现货交易对以 `{exchange, symbol}` 编辑、全局时区与指标上限；保存整份文档并带 `expected_revision`，409 重新拉取最新值。
- **主题**：涨跌色 `#d84949` / `#008300`，已用 dataviz 校验器验证浅/深背景下的 CVD 分离度（ΔE 8.3）与对比度（≥3:1）。
- **可访问摘要**：图表外隐藏的「图表数据摘要」区域输出 K 线数量、每个指标的点数与标记数，供屏幕阅读器与 E2E 断言。

## 4. 真实小样本验收（已执行）

对一个真实的 Uvicorn worker（端口 8011，同源提供前端与 API）执行：

- `GET /`、`/analysis`、`/tasks`、`/settings` → 200；`GET /api/v1/nope` → JSON 404。
- `market.sync_universes {universe_codes:["hstech"]}` → run 1 `success`，31 instruments / 30 members。
- `market.sync_hk_daily {symbols:["0700.HK"]}` → run 2 `success`，2461 根日线（`akshare`，`qfq`）。
- instrument 3 的 `1d` / `1w` / `1M` 均返回数据；两个内置指标在 209 根真实 K 线上计算成功（Donchian 27 个 marker，RSI 带 30/70 参考线），且所有 marker / 序列日期都存在于返回的 K 线中。
- 设置热生效：`PUT /api/v1/settings` 把 `hk_stock.request_timeout_seconds` 从 20 改为 25（revision 0→1）并写入 `config/settings.json`，随后恢复为 20.0（revision 2）。

真实上游失败（保留为失败，未做替代或绕过）：

| 源 | 现象 |
|---|---|
| yfinance（US、HK） | `ProviderRateLimited` —— Yahoo 限流 |
| AKShare A 股 | `Push2RateLimitError` —— 东方财富 IP 临时限流 |
| Binance / OKX | `ProviderUnavailable` —— 当前网络不可达 |

因此 US / HK / crypto 的界面验证依赖 `frontend/e2e/` 的确定性路由桩，而不是伪造的通过记录。
